# PCKL+

## Local development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and set the Supabase project URL, anon key,
and service-role key. Keep the service-role key server-side; never prefix it
with `NEXT_PUBLIC_`.

## Payment review setup

1. Apply both migrations in order:
   `supabase/migrations/20261012000000_payment_review.sql`, then
   `supabase/migrations/20261013000000_membership_wallet.sql`. They create the
   payment-review tables, membership-card balances, atomic wallet operations,
   and a private `payment-proofs` storage bucket.
2. Create an admin account in Supabase Authentication.
3. Add that account's auth user ID to `public.admin_members` using the
   Supabase SQL editor:

   ```sql
   insert into public.admin_members (user_id)
   values ('AUTH_USER_UUID');
   ```

4. Start the app and sign in at `/login`. Only user IDs listed in
   `admin_members` can load or change dashboard payments.

Top-up submissions are validated and stored as pending payments. Receipt
images stay in private storage and are exposed to authorized admins through
short-lived signed URLs. Confirming a top-up credits its card once, in the same
database transaction as the review decision; rejecting it does not change the
balance. Court and equipment checkouts debit a membership card immediately
through a row-locked database operation that also records the confirmed order.
The membership top-up page polls the persisted balance while open.

Membership card IDs are high-entropy identifiers and are currently the only
credential required for balance lookup and wallet checkout. Treat them as
secrets. The registration form issues a persisted card profile; it does not
create an authenticated Supabase user account.
Membership IDs generated by the earlier browser-only demo were not saved in
Supabase; those cards need to be reissued or imported before they can be used
with the wallet.

Court reservations and equipment rentals share one browser cart. Select a
future date, start time, and duration for available courts; add rental gear
from the equipment page; then review both together at `/cart` or go straight
to checkout.

## Court and rental inventory

Administrators can manage courts and rental equipment from the dashboard.
Customer inventory pages refresh from Supabase every five seconds, and checkout rechecks current inventory and prices on the server.
